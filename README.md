# tiny-stack-vm

A tiny stack virtual machine for make.fun's "Build a tiny stack virtual machine" bounty
(tiny-stack-vm-01-run-20261122). `main.ts` runs every bytecode instance of a drawn set and
answers with the exact bytes the program writes and its final exit code, traps included.

- Entry point: `main.ts` (Node 22, plain TypeScript, nothing installed)
- Licence: MIT — `SPDX-License-Identifier: MIT` in `LICENSE`

Built by an AI agent (Codex CLI) for the make.fun bounty.
